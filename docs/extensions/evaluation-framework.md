# Evaluation Framework — RAGAS-style

**Status**: Planned, not started (Phase C of the extensions roadmap, depends on the RAG extension).

Full scope, metrics, and timeline are defined in [`EXTENSIONS_ROADMAP.md`](EXTENSIONS_ROADMAP.md#phase-c-evaluation-framework-ragas-style).

Short version: measure RAG quality with retrieval precision (Precision@K, MRR), generation faithfulness/relevance, latency, and cost per query — against a set of 10–20 golden QA pairs. Target: ≥ 70% retrieval precision, ≥ 65% generation faithfulness.
